How agents use the five project skills

An agent is responsible for a decision or a handoff. A skill is a project guide it can follow. The search and source-audit skills identify a usable reporter movie. The specimen geometry determines which sampling skill to use. The UI skill pairs the resulting kymograph with its video and sampling region (ROI).

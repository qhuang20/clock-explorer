# Discover candidate segmentation-clock datasets

Start with the requested species and model. For mouse, distinguish intact embryos,
embryonic PSM explants, reaggregated embryonic cells and stem-cell-derived models.
Search PubMed/PMC and publisher supplements using two complementary passes:

- Combine mouse or murine with somitogenesis, somite formation, segmentation
  clock or presomitic mesoderm, then add kymograph or space-time plot.
- Repeat with time-lapse, live imaging, traveling waves or supplementary movie
  and reporter names such as Hes7, Lfng/LuVeLu, Axin2 or Mesp2. Follow references
  from confirmed studies. Spatial reporter movies can qualify without a published plot.

Check the primary caption or data record for a changing reporter signal across
a spatially resolved tissue field. Flag composites, multiple views, missing
calibration and unclear movie-to-panel correspondence for review. Exclude
brightfield-only sequences, simulations, endpoints and isolated single-cell
traces from tissue kymograph candidates.

Compare DOI, movie, specimen, reporter and condition against the project's
paper, video, comparison and dataset presentation records. A library entry can
still lack a card. Record alternate projections of a specimen together.
Return ranked candidates with DOI or stable primary link, movie/panel,
preparation, reporter, existing coverage, reason and the next unresolved check.
Distinguish caption evidence from a decoded file and a validated sampling ROI.

Hand selected candidates to [source audit](../kymograph-source-audit/SKILL.md)
for specimen matching and extraction readiness. Discovery ends at the shortlist.

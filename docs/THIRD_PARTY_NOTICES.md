# Third-party notices

The project MIT license covers original software and documentation only.
Scientific papers, images, movies, numerical data, LUTs and derived research
figures retain their original rights. They are not committed as binary assets in
this repository. Availability at a public URL is not an open license.

The following notes summarize the existing catalogue evidence. They are not a
new license grant or a legal clearance. Consult each linked publication and the
file-specific terms before reuse. Unknown or restricted terms remain unknown or
restricted. Derived outputs can retain obligations from their inputs.

The public build links to the original source for footage, figures and data
whose redistribution terms are unconfirmed. Files marked local-only in the
asset catalogue stay in the private preview. Published playback records display
the source-specific license, credit and any changes to the media.

The gallery includes independently plotted measurements and links to primary
sources. Permission to redistribute an author's underlying archive can differ
from permission to share their paper or its supplements. A software-only
archive includes source code and catalogue metadata. The public website is a
noncommercial research and teaching resource.

## Software dependencies

Node dependencies and transitive versions are pinned in `package-lock.json`;
their own notices apply. esbuild and Prettier are build tools; ESLint checks the
browser source. Scientific Python packages are optional and listed in
[analysis/requirements.txt](../analysis/requirements.txt). Their licenses are not replaced by this project.

## Attribution and corrections

The catalogue stores source URLs, input hashes, extraction notes and attribution.
If a term is incorrect or permission is withdrawn, notify the maintainer so the
source record and hosted material can be reviewed. Do not remove attribution to
make a source appear to be project-owned.
